# landscape-design-coursework

一个给 AI 编码助手用的 **Skill**（技能包）：把风景园林／植物景观规划设计的课程作业，
做成一套**可复跑、可验收**的交付物——CAD 施工图图集（DXF + PDF）、方案书（Word，图文并茂）、
一页纸简版、案例抄绘与借鉴注记、唯一交付目录，并且**验收门全绿才说话**。

它来自一门课的真实返工记录：方案书写"保留 24 株"、图纸图签写"23 株"、三张现状图排在
说它们的那一节之外、案例只写"借鉴其理念"而没给一张原图、往真车道上种了一棵树——
这些错误肉眼翻文件抓不出来，但每一条都能用几十行 Python 抓出来。

## 装

把整个目录放进技能包目录即可（Claude Code：`~/.claude/skills/`；Qoder：`~/.agents/skills/`）。

## 一条命令看它能不能跑

```bash
python selfcheck.py
```

五支脚本各跑一遍，对着 `evals/make_fixtures.py` 现场生成的假项目里**故意埋的 11 个缺陷**
逐条核"抓到没有"，应当报「埋的 11 条缺陷被抓到 11 条」。fixture 是分发包里不带的，
每次自检前重建，所以不会出现"改了缺陷清单忘了重建"。

## 五支脚本

| 脚本 | 干什么 |
|---|---|
| `scripts/check_env.py` | 环境体检：必需库、matplotlib 中文字体、本机 accoreconsole |
| `scripts/audit_manual_coverage.py` | **现读**指导手册／任务书的"图N"图目，与图纸对照表双向对账 |
| `scripts/audit_doc_figs.py` | 方案书插图四查：齐（图都用上了）／对（贴在点名它的那节）／清（印刷分辨率）／断（引用断链） |
| `scripts/gates_scaffold.py` | 三端数值点名门 + 破坏自测（门不瞎）+ 脚本→产物时效性 |
| `scripts/dxf_sheet_scaffold.py` | DXF 图幅脚手架：真比例、图层、图签、指北针、比例尺 + 越框／压图签自检 |

## 五条原则（其余都是推论）

1. **数据层是唯一真源**——底图 → `site.json` → `design.json` → `stats.json`，图纸和正文都从它派生。
2. **数字只有一个出口**——正文里的每个数由脚本现算；手抄的数字在第三轮改动后必成假数字。
3. **门要能自曝**——全绿和"判据写错了所以永远绿"输出长得一模一样，所以每条判据都要故意破坏一遍。
4. **"图文并茂"是可以被检查的**——四件事都有红字清单。
5. **不许编**——判读要有独立依据，没做的明说没做，"取不到"要先穷尽手段。

细节在 `SKILL.md`；分主题的说明在 `references/`（判据形状与容差、制图与图例双向、
手册图目查法、方案书与一页简版口径、案例检索、Windows 中文路径的九个坑、开源依赖清单）。
