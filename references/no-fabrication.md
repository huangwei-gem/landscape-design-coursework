# 不许编：结论要能在地图上找到第二件事

这类作业真正的失分方式不是图画得丑，而是**写了做不到的事**。四条规矩，
每条都对应一次真实返工。

## 1. 每个判读结论都要有独立依据

判读出来的东西（树种、保留树、现状植被边界）不能只有影像自己作证。做法：
取 OpenStreetMap 的 `landuse`／`natural`／`leisure`／`amenity` 面（和本流程无关的第二来源），
裁进研究区后做分区统计，给**细类一致率 + 大类一致率**两个口径；分歧大的地方回到最高分辨率
原始正射逐片看图，并把结论——**包括判读错在哪**——写进正文。
覆盖不到的类要明说「无外部证据」，不许混在「已核验」里。

拿不到外部数据时（本项目：无影像底图服务、OSM 该片区无植被面），就在正文里写"取不到"，
并说清你换过哪些手段（见第 3 条）。

## 2. 不可溯源的句子会被判不可过

「100−32=68」这种在正文里现算的补数，评审看不出你减的是哪个数——写成 JSON 字段现算。
「已按规范设置灌溉」而你没画灌溉图，就是假声明。每一句"已做"都要能指到一张图或一个数字。

## 3. 「取不到」要先穷尽手段再说

说"这个数据拿不到"之前，必须真的试过：换镜像、换 UA、POST、开浏览器实际访问、
换协议、换公开接口。本项目实测过：
- 天地图／高德／OSM 瓦片服务全部试过，结论是无影像底图服务可用 —— 这句话是有过程的；
- AutoCAD 的 MCP 桥接装好了但 COM 不可达 —— 试过才敢说；
- GitHub 下载被证书吊销检查卡住 → `curl --ssl-no-revoke` + gh-proxy 镜像，
  下完**必须校验 zip**（镜像会返回半个文件）。
误判了要明写更正并加一条防回归检查，别悄悄改掉。

## 4. 没做的作业要明说没做

交付前对着任务书逐条列：做了的指到图号，没做的写"未做，原因 X"。
本项目到最后仍有一项作业只交了图纸没交视频，正文里就写着没交——
**声明未做比蒙混过去安全得多**，因为蒙混一定会被追问，而追问时你没有第二套说法。

## 判读值的正确写法

分三档，在表里就分栏：

| 档 | 来源 | 例 | 能不能直接放样 |
|---|---|---|---|
| 实测 | 底图／网格量算 | 位置、高程、坡度、距建筑距离 | 能 |
| 图上判读 | 手绘现状图／影像 | 树种、符号等级 | **放样前必须逐株复核** |
| 按规格推定 | 树种成熟规格 × 折减系数 | 树高、冠幅、胸径、分支点高 | 只能作参考 |

最后一句必须写在表下面：「后两档均为图上判读值，放样前必须逐株实测复核并回填本表」。
这句话不是免责，是告诉读者你的数据边界在哪——被问到"你这树高怎么来的"时，
它就是你唯一站得住的回答。
