# 制图：图纸体系、比例、要素

工具：`scripts/dxf_sheet_scaffold.py`（`--demo` 出一张干净 A2，`--demo-bad` 出两张红字，
`--preview` 不装 AutoCAD 渲 PNG）。

## 一张注册表管全套图纸

```python
SHEETS = [
    # 图号   图名                    图幅  比例    对应作业   手册图号
    ("PL-00", "种植施工说明·图纸目录", "A2", "—",    "通用",    ""),
    ("PL-01", "场地现状与范围图",      "A2", "1:500", "作业1",  "图1"),
    ("PL-04", "种植设计总平面图",      "A2", "1:500", "作业2",  "图5"),
    ...
]
```

图名、张数、比例、目录、图签、方案书图注、README **全部由这张表派生**。绘图脚本自己传的
图名要 assert 等于表里的值——"图签写 A3、图幅其实是 A4"这类分歧就是这么留下的。
加一张图要动的地方：表 + 一个绘图模块 + 手册对照表 + 方案书图注 + 点名门。少动一处，
门就会在下次跑的时候告诉你少了哪一处（这就是先立门再画图的好处）。

## 比例：1:500 必须是真的

- 模型单位＝毫米，图框按 ISO 幅面真实毫米画。实地一米在图面上是 `1000/分母` mm
  （1:500 → 2.00mm）。
- **幅面放不下就换大幅面，不要靠打印时"适合页面"缩放**——那会让图签上标的 1:500 变成假的。
  本项目 A4 上放不下 60m 见方的场地还要求 1:500，最后放大到 A2 才是真比例。
- `fit()` 返回缩放系数 k，`k<0.995` 就报警：你标了 1:500 实际画成 1:620。
  这一条能抓住"改了图框没改 fit"的错。
- 一幅图两个比例（总面 1:500 + 区位 1:8000）时，比例真源只能有一个函数，
  图签和面板标注都问它；两处各算一遍就会互相打脸。

## 每张图该有的要素（缺了就报）

指北针、直线比例尺（分划由 mm_per_m 真算，别照抄别人的）、图例、图签（图号／图名／比例／
图幅／设计／审核）、比例与图幅自述。任务书点名的要素要逐张查，不能"图集里有就行"。

**图例↔图示双向门**：图上画了的符号，图例必须列；图例列了的，图上必须真画。
单向查会被"图例照抄上一张图"糊过去。

## 剖面／立面要真采地面线

剖面图不是画两条波浪线。做法：沿剖面带把地形网格的高程按桩号插值出来，画出来的地面线
和平面图上的高程点能对上；立面同理。本项目还有一条：标题写了「1.70m 人形参照」就真的按
1.70m 画一个人，别只写不画。

## 版面塞不下怎么办

右栏（注记＋图例＋统计表）是重灾区。自适应装箱：

```python
ncol = max(1, round(w / 215))            # 先按经验列数
while ncol < nmax and 放不下(ncol): ncol += 1
assert 剩余高度 >= 0, "右栏放不下：注记 %d 行＋图例 %d 行顶到统计表"
```

最后那句 assert 很重要——没有它，超出图框 12mm 这件事只有打印出来才看得见。
同理给每张图一个**线数预算**（实体数上限）：接近 90% 报提醒，超了报红字。
版面开始互相压字之前，数字先告诉你。

## 出图与目视

- **PDF 走 ezdxf 渲图**（`preview()`），不要指望 accoreconsole：它不加载 .pc3 打印样式，
  出来的线宽颜色和屏幕上不一样。accoreconsole 只用来证「真 AutoCAD 打得开」。
- 合订 PDF 的页数是硬证据：图纸 19 张、PDF 18 页 → 有一张没进去。
- **每张图都要用眼睛看过**。脚本全绿不等于图是对的（本项目栽过一次：验收门自己带病，
  掩护了一个真缺陷）。做法是把 N 张 PNG 拼成 2~3 张接触表，一次看完整套，
  逐张问：字压字没有、符号出框没有、图例和图上对得上没有、空白是不是太大。

## 通行组织图：什么时候必须单开一张

场地里只要有现状车行路（尤其是有分叉／交叉口的），图集里就得有一张交通图，回答四件事：
车行通道在哪、多宽、整幅禁种多少面积；交叉口几处、各几条线汇合；人行带贴在哪一侧、
多宽、新增硬景多少；竖向动不动。判据全部现取数据层，一条线都不手画。

两个坑：

1. **比例要和总平面一致。** 让两张能叠图核对。按幅面反算时 A2 会自己挑到 1:500 之外的大比例
   （本项目挑成了 1:250），图面比总平面大一倍，反而读不出关系——注册表里把这两张钉成同一档。
2. **新加一张大幅面图最容易留白带。** 图面只占场地实际尺寸，A2 装 111×76m 就是 222×152mm，
   右栏没有统计表就空掉半幅。加图时同时决定右栏装什么（一览表／分区表），别只把注记一丢了事。

半幅外扩画路幅边线时，端点会探出红线窗口——一律走裁剪（与画现状线划同一支笔），
不要直接落笔，否则"越红线"门会抓到几条几毫米的碎线。

## 把设计人的手绘底本转进 CAD：算法给位置，人工给类型

老师／设计人给一张手绘现状图（照片），要求"里面的植物每一株都绘到 CAD 上"。
这类活的正确分工是：**算法负责"哪里有符号"，人负责"那是什么符号"**。反过来做一定返工。

为什么不能让算法判型（本项目实测，三条都会骗人）：

1. **判型指标会被自己的预处理污染。** 用"白孔面积／外接圆面积"分圆和方（圆≈1.0、方≈0.64），
   前提是掩膜没动过孔的边界。但为了连笔迹通常会做 3×3 膨胀，它同时向内吃掉约 1px；
   符号孔半径只有 5~9px，1px 就能把圆的比值从 0.95 拽到 0.6——圆和方在直方图上连成一片
   （0.65~0.95 无谷），一个阈值切下去，那一整排黑铅笔圆就全进了灌木层。
   要量形状，先把笔宽补回去（孔膨胀 5×5）再量；并且**同时看两个指标**：
   面积／外接圆（圆→1、方→0.64）与面积／最小外接矩形（方→1、圆→0.785），单指标没有谷就不要硬切。
2. **闭合假设不成立。** 铅笔圆常留一个小缺口，孔与外界一通就整圈漏检；红笔三角的孔只有
   十几 px，面积阈值一挡就没影了。补三路：掩膜做闭运算补笔缝、Hough 圆（靠梯度不看闭合）、
   按色相取红／绿笔构件。**先求全，再由人工剪**——漏检比误检贵得多，误检一眼能删，漏检看不见。
3. **取色不能在整圈取中位。** 圈上大半是纸白（铅笔淡、拍照曝光不均），中位饱和度根本没进笔，
   于是全图 115 个"黑墨"，而纸上明明一片绿方框。只在"确实是笔迹"的像素（灰度低于阈值
   或落在掩膜上）上取中位饱和度与色相。

落地做法（一次配准，两件工作面，逐格可复核）：

- **编号联络表**：把所有候选裁成小图，按空间顺序铺成每页 48 格的表，每格左上标格号、
  左下标算法自判值。人只看形状逐格写"圆／方／三角／删"。删掉的那批通常是虚线两笔之间的
  白缝、标高数字（"77.9"就是两个圆孔）、建筑台阶线、桌角。
- **阅读块**：把照片按 4× 放大切成 12 块，叠上候选圈与坐标网，专门找**没被圈到的符号**。
  这一步补出来的数量往往很可观（本项目 42 处，占最终 148 个符号的 28%）。
- 人工判定表落盘成 json，键＝候选下标，脚本断言"表里格数 == 本次检出数"。这样任何对检出
  的改动都会当场撞断言，而不是把人工结论错位套到另一批符号上。
- 交付里留一张**复核图**：把判定后的符号按配准画回照片。别人问"你画对了吗"，
  给这一张比说十句都有用。

两条通用教训（同一轮踩的，跟绘图无关但同样致命）：

- **样本不足不许整段跳过检验。** 原来写"配对少于 8 对就不算相关"，转录改完只剩 7 对，
  于是 rho/p/k 全是 NaN，判读说明里印出"实测 k 在 nan~nan 之间来回跳"——一句话把整份
  判读变成假话。改成阈值放到 3、照算，并把 n 一起印出来，让读者自己权衡检验力。
- **解算脚本里别拿解算系数当循环变量名。** 检测循环里写了 `A = contourArea(...)`，
  把仿射配准的 `A` 覆写了，之后每个符号都用面积当比例去反算，全部飞出场地外几万公里。
  防线不是小心，是**落点门**：符号解算出的场地坐标必须落在场地外扩若干米内，否则当场断言。
