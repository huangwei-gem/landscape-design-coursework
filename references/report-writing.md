# 方案书：图文并茂是能被检查的，不是形容词

工具：`scripts/audit_doc_figs.py`（齐／对／清／断四件事）。这一篇讲结构和文案口径，
因为门只能查形式，内容对不对要按这里的规矩写。

## 结构（诊断与治理合成一册）

标题就叫「……综合调查诊断与治理方案报告」／「……种植规划设计方案书」，
**第一部分 调查与诊断、第二部分 方案，章节连续编号，不要交两册**。
分册交上去，老师要自己拼，而且两册之间一定会出现数字不一致。

```
一、场地与范围      1.1 位置与范围  1.2 地形与竖向  1.3 现状植物（留不留）
二、设计与立意      2.1 主题与四条立意  2.2 结构（一核一环五区四时这类）
三、案例借鉴与迁移  3.1 案例原图  3.2 迁移表（借什么／怎么落／落在哪张图）
四、种植设计        4.1 分区与配比  4.2 苗木规格  4.3 林缘线与群落
五、专项            铺装／灌溉／照明／养护
六、图纸目录与作业对应
七、结语
```

章节重心跟着课程走：植物景观课就把种植放到最厚的位置，别把铺装写成半本。

## 图文并茂的四条硬标准

1. **出过的图全部用进报告**。不只是成果图，中间过程的分幅图、统计图、判读样例、核验接触表
   都算图。交付前跑 `audit_doc_figs.py --figdir`，"磁盘上有、正文里没用"的清单必须为空。
2. **每张图贴在说它的那一节**。图注自己写「判读依据见 1.3」而图排在 1.2 末尾，就是分家——
   读者顺着图注去找会扑空。图注行不算「正文提到」，否则每张图都靠自己的图注作证，门永远绿。
3. **图号在合并后按文档顺序重排**，并同步改写正文里的引用。改写时要**跳过插图行**，
   否则会改掉图片文件名（本项目踩过一次）。
4. **印得清楚**：每张图入册前过 150dpi 门（按真实打印宽度算，见 `audit_doc_figs.py` 的 dpi 段）。
   并在正文里报出「最低一张多少 dpi」，别只说"高清"。

## 详版之外再出一版简版（一页纸）

老师／甲方常常不会先翻 74 页。简版不是摘要，是**同一套数字的另一种排法**，所以它必须：

- **只有一个数字出口**。详版从 `stats()` 取数，简版也从同一个 `stats()` 取；
  两边都不许写字面量。否则简版会先过期。
- **独立成端进点名表**。给它一个端名（`BRIEF`），把题目、立意四句、关键数字表都列成判据。
  它和详版的差异应该是"少说了话"，不能是"说错了话"。
- **有硬的一页门**。两道，一道比一道早发现问题：
  生成时 `assert 字数 < 上限`（上限是一页纸的字数预算，不是荣誉数字；超了就是开始加话了，
  删话而不是加页。本项目随内容加过一次：1500 → 2600，因为要放一张手册原图图版）；
  排版后 `assert 页数 == 1`（用 Word/打印实测页数，不是估的）。
  图放不下就缩图宽、并排、压行距，不是加页。**并排比叠放省纸**：预览图多是 A3 横幅
  （高＝宽/1.412），两张并排占的行高只有一张的高，不是两张的和——本项目就是这样把
  总平面与结构图塞进同一页的。顶到极限时页底余量会只剩几 pt，这时**别再放大**，
  要空间只能从别的行删；注释里写清当前实测余量，别写"应该放得下"。
- **纸要显式设。** python-docx 新建文档默认是 Letter，注释里写"一页 A4"而没设
  `page_width/page_height`，等于交给老师的纸比图纸那套 A 系列大一号、还矮 50pt。先定纸再谈尺寸。
- **字数门要连表格一起数。** 只数正文段落，等于给"往表格里塞话"留后门——量的是整页有多少字，
  不是它们落在哪种容器里。抬上限必须在注释里写清是谁点的、加了什么，否则这道门只会越抬越松。
- **每句立意带一个数**。一页纸没有论证空间，数字自己论证。

## 数字与口径

- 所有数字从 `stats.json` 现算填进句子。补数（`100-x`）也要现算字段，不能让正文自己减。
- **两个口径分开说**。例：铺装总面积 vs 净新增硬地——「其中 268㎡ 铺在现状路面上、只换面层
  不新占地面，净新增硬地 143㎡」。混着说会被问「你到底加了多少硬地」。
- **取值口径先说清楚**：哪些是实测底图来的（可直接放样），哪些是图上判读的（放样前必须复核），
  哪些是按树种成熟规格推的（冠幅、胸径、分支点高）。分栏写，别假装都做过实测。
- 判读值要给出为什么只能判读：例如手绘现状图的符号是点符号（直径 1.6~2.4m 之间、
  与真实冠幅的 Spearman rho 不显著），量不出逐株冠幅——**这句话本身就是证据链的一部分**，
  写出来比藏着更可信。
- 统计上没通过的事不许假装通过。逐株对应做 Mann-Whitney 得 p=0.42，就写"没有通过"，
  并把方案怎么受影响写清楚。

## 章节自指与前向承诺

正文里写「口径见九、种植施工与养护要点」「逐行比对见 6.1」时，那一章／一节必须真的存在
并且真的有那句话。这类断链是纯文字的，文件存在性检查看不见。
本项目实测过一次：6.1 写完顺手承诺"九、里为它单列了一条进场要求"，而九、当时没有——
图纸与数字全绿，读者照着那句话去找就扑空。`audit_doc_figs.py` 的落点检查是同一类东西。

## 读我（README）

交付目录里放一份，写三件事：这套东西怎么打开（先看哪张）、每个目录是什么、
**哪些作业要求对应哪张图**。老师翻交付是从读我开始翻的。
